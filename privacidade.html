O que é o app

O Postador ESFV é uma ferramenta pessoal, usada somente pelo dono do canal do YouTube E Se Fosse Você? para enviar e agendar os vídeos do próprio canal. Ele usa os Serviços de API do YouTube. Ao usar o app, você concorda com os Termos de Serviço do YouTube. O uso dos dados pelo Google é regido pela Política de Privacidade do Google.

Quais dados o app acessa

Com a autorização da Conta Google do dono do canal, o app acessa apenas:

  • o nome e o ID do canal do YouTube, para confirmar que a conta certa foi autorizada;
  • a permissão de enviar vídeos a esse canal, com título, descrição, tags, categoria, idioma e horário de publicação.

O app não lê e-mails, contatos, comentários, estatísticas nem dados de outros usuários ou espectadores.

Como os dados são usados e guardados

A autorização (token de acesso) fica salva apenas no computador do dono do canal, em um arquivo local. Os vídeos e textos enviados vêm de arquivos do próprio computador do dono. O app não tem servidor, não usa cookies, não exibe anúncios e não envia dados a nenhum lugar além da API do YouTube.

Compartilhamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros.

Como cancelar o acesso

O acesso pode ser revogado a qualquer momento na página de permissões da Conta Google: security.google.com/settings/security/permissions. Basta apagar o arquivo de token local para que o app deixe de ter qualquer acesso.

Privacy Policy

About the app

Postador ESFV is a personal tool used only by the owner of the YouTube channel E Se Fosse Você? to upload and schedule that channel's own videos. It uses the YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

With the channel owner's Google Account authorization, the app accesses only the channel name and ID (to confirm the right account was authorized) and permission to upload videos to that channel with their title, description, tags, category, language and publish time. It does not read email, contacts, comments, analytics or any other user's or viewer's data.

Use and storage

The OAuth token is stored only on the channel owner's own computer, in a local file. The app has no server, uses no cookies, shows no ads and sends data nowhere except the YouTube API.

Sharing

No data is sold, shared or transferred to third parties.

Revoking access

Access can be revoked at any time at security.google.com/settings/security/permissions, and deleting the local token file removes all access.
