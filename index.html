Postador ESFV

Ferramenta pessoal de publicação do canal E Se Fosse Você? no YouTube

O Postador ESFV é um script de uso interno, executado apenas pelo dono do canal no próprio computador. Ele envia ao YouTube os vídeos curtos já produzidos e aprovados, com título, descrição, tags e horário de publicação, usando a YouTube Data API v3 oficial.

Não é um serviço aberto ao público: não há cadastro, não há login de terceiros e nenhum dado de visitantes é coletado.

Desenvolvido com os Serviços de API do YouTube
Este app usa a YouTube Data API. Ao usá-lo, você concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

English

Postador ESFV is a private, single-user tool. The owner of the YouTube channel E Se Fosse Você? runs it on their own computer to upload and schedule the channel's finished videos (title, description, tags and publish time) through the official YouTube Data API v3. It is not offered to the public and does not collect data from anyone else.
